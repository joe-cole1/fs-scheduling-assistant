# v0.3 provenance — historical reference only

The original `Pantons_F16_Scheduling_Analysis_System_v0.3.docx` and `Pantons_Scheduling_Starter_Kit_v0.1.zip` were read without modification. They were supplied outside this repository; neither binary was present on the original main branch.

[SOURCE_SHA256.txt](SOURCE_SHA256.txt) records their original byte hashes. [system-v0.3-text.md](system-v0.3-text.md) is a body-text and table extraction of the original DOCX for review. It is not the original binary, does not preserve page layout, and is not a new approved edition. No original policy wording was intentionally rewritten in that extraction.

Do not use this archive as the controlling v0.4 prompt. In particular, historical v0.3 restrictions on target-week outcomes have been explicitly revised for legitimate execution reflows, and old run modes have been replaced by phase controls. The [crosswalk](../../docs/v0.4/policy-crosswalk.md) documents the changes.
