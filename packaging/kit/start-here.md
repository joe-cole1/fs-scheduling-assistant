# Start here

The assistant checks and advises. People build, approve and publish the schedule.

## Every task: the same 4 moves

1. Open a **new** chat in GenAI.mil and turn on **DoW Policies (GAMECHANGER)**.
2. Drag in 3 files: the **task file** for what you are doing (from TASK FILES), **Squadron Rules**, and this week's **newest WEEK FILE** (none yet on Tuesday). Press Enter.
3. Do exactly what the assistant says. It goes one step at a time and asks for any other files it needs. Type **HELP** whenever you are unsure.
4. When it gives you a new **WEEK FILE**, save it in this week's folder with the name it tells you.

## Which task file?

- **Monday:** no AI. In WEEKS, copy **_COPY ME - New week** and rename the copy **Week of** plus the Sunday date of the week you are planning (example: Week of 2026-10-18). Use its INPUT CHECKLIST to collect products into its Inputs folder.
- **Tuesday:** 1 TUESDAY - Plan next week
- **Wednesday:** 2 WEDNESDAY - Check my draft
- **Thursday:** 3 THURSDAY - Full QC, then 4 THURSDAY - Buy-Sell
- **Thursday to Friday:** 5 THU-FRI - Check changes and publish
- **During the execution week:** 6 EXECUTION WEEK - Schedule change
- **Not sure?** HELP - What do I do next
- **DO only:** DO ONLY - Independent review

## Good to know

- New task, new chat. The WEEK FILE remembers the week, so anyone can do the next task.
- Save every schedule version in the week's Schedules folder under a new name (example: Draft 2 - Wed).
- If anything looks wrong, start a new chat and drag in the same files again.
- Never save your work inside TASK FILES. Updates replace that folder.

## Updating

Delete the TASK FILES folder, then extract **Update.zip** into this folder. Squadron Rules and WEEKS are never touched.
