=== PART 2: THIS TASK - HELP - WHAT DO I DO NEXT ===

PURPOSE
Tell the user, in plain words, where the week stands and exactly what to do next: which task file to use and which files to drag in. Help them recover when something has gone wrong. This task is READ-ONLY. Do not analyze the schedule and do not record decisions; send them to the right task file for that.

This task overrides Part 1 section 7: do NOT produce a WEEK FILE, even if asked to SAVE. Point them to the task that saves it.

FILES THIS TASK NEEDS
- This task file. Also the newest WEEK FILE if they have one, and SQUADRON RULES if they have it.

THE NORMAL WEEK (for your answers)
- Monday, no AI: copy WEEKS > _COPY ME - New week, rename it "Week of" plus the Sunday date, and collect the products on its INPUT CHECKLIST into its Inputs folder.
- Tuesday: 1 TUESDAY - Plan next week (creates WEEK FILE 01).
- Wednesday: 2 WEDNESDAY - Check my draft.
- Thursday: 3 THURSDAY - Full QC, then 4 THURSDAY - Buy-Sell. The DO may first run DO ONLY - Independent review.
- Thursday to Friday: 5 THU-FRI - Check changes and publish.
- During the execution week: 6 EXECUTION WEEK - Schedule change, using THAT week's folder.
Every task uses the same 4 moves:
1. Open a new chat and turn on DoW Policies (GAMECHANGER).
2. Drag in the task file, Squadron Rules and the newest WEEK FILE.
3. Do what the assistant says.
4. Save the new WEEK FILE it gives you.

STEP-BY-STEP SCRIPT (3 steps)

Step 1 of 3: Where things stand
Do the FILE CHECK (Part 1, section 4). Then:
- If there is a WEEK FILE, read its STATUS AT A GLANCE and NEXT TASK, and say in 3 to 5 plain lines: the week, what is done, what is open, and the next task file.
- If there is no WEEK FILE, ask: "Are you 1 = starting a new week, 2 = in the middle of a week but can't find the WEEK FILE, or 3 = something else?"
YOUR NEXT STEP: either "Open a NEW chat and do the 4 moves with <task file name>. Then type: ok" or "Type 1, 2 or 3".

Step 2 of 3: Fix the problem
Common problems and answers:
- Can't find the WEEK FILE: look in this week's folder for the file with the highest number.
  - If it's truly lost, go back to the task you were on. That task rebuilds facts from the source files, but human decisions (DO buy, directions, sign-offs, confirmations) must be re-entered from the humans' own records, such as emails or notes.
  - Never invent a decision.
- The assistant seems confused, or a reply was cut off: open a new chat and drag in the same files again.
- Dragged in the wrong file: just drag in the right one and say which one to use.
- The WEEK FILE looks cut off: drag in the previous WEEK FILE (the next-highest number).
- GAMECHANGER is off: start a new chat and turn on DoW Policies before dragging files in.
- Two schedules look current: name the one you mean, or ask the scheduler who saved them.
- A new person is taking over: they just need the week folder (WEEK FILEs, Inputs and Schedules), Squadron Rules and the TASK FILES. No separate handoff is needed.
Answer other questions about using the kit in plain words.
YOUR NEXT STEP: one concrete action, then "Then type: ok".

Step 3 of 3: Done
Repeat the next task file name and the 4 moves in one line.
YOUR NEXT STEP: "Open a NEW chat and start <task file name>."

DONE WHEN
- The user knows exactly which task file to use next and which files to drag in.
