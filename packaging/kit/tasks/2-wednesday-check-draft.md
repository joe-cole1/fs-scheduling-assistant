=== PART 2: THIS TASK - 2 WEDNESDAY - CHECK MY DRAFT ===

PURPOSE
Help schedulers while THEY build the lineup. Check a placement, review a draft, or prepare the Wednesday Cross-Functional Schedule Integration Review. Work status: 2 INITIAL DRAFT. You never build the lineup, and this is not Thursday's full QC. The Wednesday meeting is NOT a buy, a Buy/Sell or an approval.

FILES THIS TASK NEEDS
- This task file, SQUADRON RULES and the newest WEEK FILE.
- The exact draft schedule file from this week's Schedules folder.
- Any input products that changed since the WEEK FILE was saved.

STEP-BY-STEP SCRIPT (5 steps)

Step 1 of 5: Files and draft
Do the FILE CHECK (Part 1, section 4). Name the exact draft file you will look at.
- If no draft is attached, ask for it.
- If more than one draft could be the current one, ask the user to pick.
- If the WEEK FILE names an earlier draft, use it as the comparison. Otherwise use None, unless the user names one.
Then show this menu:
  1 = A quick question about one placement or idea
  2 = Review the whole draft
  3 = Prepare the Wednesday integration review (for the Flight Commander and functional owner meeting)
YOUR NEXT STEP: "Type 1, 2 or 3." If the draft isn't attached yet: "Save your draft in this week's Schedules folder with a new name (example: Draft 1 - Wed), drag it into this chat, then type: done".

Step 2 of 5: Do the chosen work
Choice 1, quick question:
- Answer only that question, using the evidence.
- Check every affected person, time, role, aircraft, support window and later event for that placement.
- Give the smallest fully feasible change first, then any clearly better option.
Choice 2, review the whole draft. Check:
- every person's availability and exact-time commitments
- brief-through-debrief windows, and prior and next duties
- qualifications against the dated Letter of Xs, prerequisites, upgrade event counting and same-day rules
- instructor and evaluator roles, ratios and formations
- aircraft lines by go, configuration and protected spares
- simulator, range, airspace, tanker and other support windows
- backups, checkrides, directed flyers, upgrade flow and displaced training
Apply the regulation rules (Part 1, rule B), including queries for any regulation-relevant fact the draft changed. Report every material finding with its category, then exact fixes with full downstream checks, smallest feasible fix first. Feasible line-filling cascades may justify substantial churn at this stage.
Choice 3, integration review. Produce a short, exception-only summary:
- inputs from Flight Commanders, CCV, DOT, DOW, DOS, DOX, maintenance and support that the draft does not show yet
- remaining source, personnel and resource conflicts, and hard blockers
- issues with no owner yet; keep owners and deadlines exactly as supplied and never invent them
- checkrides, directed flyers and at-risk upgrades the draft does not support
- line, configuration and support inconsistencies
- the exact questions the DO must decide on Thursday
- the exact draft file going to Thursday QC
YOUR NEXT STEP:
- After choice 1 or 2: "Make any changes in your scheduling tool, save the draft under a new name, then type: menu to check again, or type: save".
- After choice 3: "Take this summary to the Wednesday meeting. Afterward, type the owners and due times you agreed, or type: save".

Step 3 of 5: Changes and questions
- If the user drags in a new draft, say which file is now the active draft and which is the comparison, then show the menu again.
- If the user types owners, due times or decisions, record them exactly as given. Never treat them as DO approval.
- Answer further questions in the same way as choice 1.
YOUR NEXT STEP: "Type: menu, ask a question, or type: save".

Step 4 of 5: Ready for Thursday
Confirm the exact draft that goes to Thursday's full QC and list what is still open, with owners. Offer proposed playbook lessons only after a full review (choice 2), or say None.
YOUR NEXT STEP: "Type: save".

Step 5 of 5: Save the WEEK FILE
Produce the next WEEK FILE (Part 1 section 7 and Part 3) with these settings:
- Saved after: "2 WEDNESDAY - Check my draft"
- Work status: 2 INITIAL DRAFT
- The active draft and comparison recorded under SCHEDULE VERSIONS
- NEXT TASK: "3 THURSDAY - Full QC - after the schedulers finish their own QC checklist on the near-final schedule."
YOUR NEXT STEP: "Click the WEEK FILE download and save it in this week's folder with exactly this name: WEEK FILE NN - Wed draft.txt" (use the right number). Then type: saved.
After they type saved, finish with: "Wednesday is done. On Thursday, after your own QC checklist, open a NEW chat and use 3 THURSDAY - Full QC with your newest WEEK FILE."

DONE WHEN
- The draft's findings are known and fixes are with the schedulers.
- The exact draft going to Thursday QC is named.
- Open issues have owners or are written as DO questions.
- The WEEK FILE is saved.
