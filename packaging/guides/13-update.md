# Update for next week

Adopt a routine update before the next planning week. The package number in document headers identifies the installed version.

- [ ] Download Update_Existing_Setup.zip for the intended release.
- [ ] Extract it into a temporary folder.
- [ ] Read UPDATE INSTRUCTIONS.docx.
- [ ] Back up the existing System folder and START HERE.docx.
- [ ] Replace the entire existing System folder with the supplied System.
- [ ] Replace START HERE.docx with the supplied copy.
- [ ] Review any PERSISTENT MIGRATIONS.docx in the temporary update.
- [ ] Merge only the listed persistent guidance changes after human review.
- [ ] Keep Local Guidance, the weekly-folder template and every active or completed week.
- [ ] Start the next week with 03 Tuesday - Start the Week.

Use an update ZIP for existing installs. For rollback, use the prior release’s update ZIP and the same System-only replacement. Preserve local guidance, approvals and actuals.

**Finished when:** The new package number is visible. If a System change is urgent during an active week, use 12 to resume the exact current state in a new chat; do not invent new approval.
