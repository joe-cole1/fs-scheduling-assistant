# Wednesday build

Schedulers build the lineup. Use the assistant to review your draft, then prepare the Cross-Functional Schedule Integration Review.

- [ ] Build the schedule in your normal scheduling tool.
- [ ] Save the working draft with a unique filename in Schedules.
- [ ] Upload that exact draft to the weekly chat.
- [ ] Paste the draft prompt below.
- [ ] Check the draft filename shown by the assistant.
- [ ] Follow the assistant’s one next action to resolve findings.
- [ ] Upload the integrated draft before the Wednesday meeting.
- [ ] Paste the integration prompt below.
- [ ] Have Flight Commanders and source owners verify their inputs.
- [ ] Assign remaining issues to an owner and due time.
- [ ] Save the integrated draft for Thursday QC.
- [ ] Save the complete weekly record in Working Record.

## Draft prompt

Copy **System → Prompts → 05_Review_Draft.txt** or paste the complete text below.

```text
Do not delegate to subagents. Review this working draft.
```

## Integration prompt

Copy **System → Prompts → 05_Integration_Review.txt** or paste the complete text below.

```text
Do not delegate to subagents. Prepare the Wednesday integration review.
```

The Wednesday meeting verifies inputs and assigns issues. It does not approve or buy the schedule.

**Finished when:** One exact integrated draft and its remaining decisions are identified for 06 Thursday - Full Schedule QC.
