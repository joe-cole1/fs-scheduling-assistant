# First time squadron setup

Use this package to establish your squadron’s guidance before starting weekly scheduling. The files in Local Guidance are draft starters; supply your actual rules and record the DO’s decisions.

- [ ] Open First Time Setup → Instructions → 01 First time setup.docx.
- [ ] Complete that checklist with your current local sources.
- [ ] Save confirmed guidance in Local Guidance.
- [ ] Open First Time Setup → Instructions → 14 Check the Setup.docx.
- [ ] Record the actual trial results with the setup owner and DO.
- [ ] Start weekly work with System → Instructions → 02 Monday - Inputs Due.docx.

## Where to work

**First Time Setup** contains the one-time instructions, setup prompts, setup primer and validation reference. Keep these separate from weekly work.

**System** contains the weekly instructions, prompts and assistant upload file. For Tuesday planning, use **03 Tuesday - Start the Week.docx**.

**Local Guidance** holds the human-maintained profile, references and playbook. A draft starter is not approved policy. Existing approved guidance stays authoritative.

**COPY THIS FOLDER FOR EACH NEW WEEK** includes an input checklist in Inputs. Copy the folder, rename it for the execution week, and keep that week’s sources, schedules and Working Record there.

Every complete prompt includes **Do not delegate to subagents**. No specific model is required. Humans build, edit, approve and publish.

Once guidance is established, use the weekly System. The already-configured Pantons download opens directly to weekly work.
