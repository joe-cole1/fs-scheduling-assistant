# Tuesday startup

Start next week’s planning. Use your existing squadron scheduling folder; each box is one action.

- [ ] Copy COPY THIS FOLDER FOR EACH NEW WEEK.
- [ ] Rename the copy Week of YYYY-MM-DD using your approved counting week’s first date.
- [ ] Use Inputs → INPUT CHECKLIST.docx to collect the source products.
- [ ] Open a new GenAI.mil conversation for that week.
- [ ] Enable DoW Policies Beta (GAMECHANGER) if available.
- [ ] Upload System → UPLOAD THIS TO START.docx.
- [ ] Upload the current files from your squadron’s Local Guidance folder.
- [ ] Upload the available files from the new week’s Inputs folder.
- [ ] Paste the startup prompt below.
- [ ] Check the execution dates shown by the assistant.
- [ ] Follow the one next action given by the assistant.
- [ ] Save the complete weekly record in the week’s Working Record folder.

## Startup prompt

Copy **System → Prompts → 03_Start_Next_Week.txt** or paste the complete text below.

```text
Do not delegate to subagents. Read UPLOAD THIS TO START.docx and my local guidance. Help me plan next week. Give me one next action at a time.
```

Name any missing file or unavailable setting in the chat. The assistant should explain the affected limits and continue supported work. GAMECHANGER gaps stay CANNOT VERIFY.

**Finished when:** Checkride and upgrade priorities, candidate windows and major constraints are identified. Use 04 to continue planning or 05 when schedulers start the lineup.
