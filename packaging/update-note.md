Package 0.5.5 adds a publication-grounded regulatory QC layer to the main Gemini scheduling workflow using GenAI.mil's **DoW Policies Beta (GAMECHANGER)** connector.

For publication-derived currency, qualification, crew-rest/duty, evaluation, syllabus/prerequisite, event-credit, recurring-training and similar requirements, Gemini may now make a regulatory determination only from a sufficiently traceable publication retrieved through GAMECHANGER. Model memory, generic military knowledge and ordinary web search are explicitly prohibited as fallback regulatory evidence. Results use four statuses: **SOURCE-BACKED OK**, **SOURCE-BACKED ISSUE**, **CANNOT VERIFY**, and **SOURCE CONFLICT**. If the connector is unavailable or cannot provide a sufficiently traceable applicable source, normal scheduling work continues but the affected publication-based check remains CANNOT VERIFY.

The weekly workflow now builds a **Weekly Publication Rule Ledger** with stable P-### IDs. Tuesday planning creates the initial publication-rule/currency baseline. Thursday full QC re-queries GAMECHANGER against the actual near-final schedule before Buy/Sell. Post-Buy/Sell changes and execution reflows perform delta queries only for affected publication-driven checks. Buy/Sell and publication reports preserve unresolved source conflicts and unverified checks rather than claiming blanket compliance. GAMECHANGER evidence does not grant approval or a waiver and does not change the Thursday Buy/Sell authority model.

Existing installations should adopt this System update at the next scheduling-week boundary using the normal **Update an existing setup** package. Local Guidance and weekly work are preserved; no persistent migration is required. In the new weekly Gemini conversation, enable **DoW Policies Beta (GAMECHANGER)** when available before Tuesday planning. Actual GenAI.mil connector behavior remains subject to the documented synthetic rehearsal and operational validation; repository/package checks alone do not prove connector or model compliance.
