Package 0.5.2 reorganizes the operator manual around the actual weekly scheduling rhythm. System → Instructions now contains a separate Word guide for Monday inputs, Tuesday startup, Tuesday planning, Wednesday build, Thursday full QC, optional DO adversarial review, Thursday schedule buy/sell, post-buy/sell implementation, Friday final QC/publication, execution reflows, active-week handoff, updates and setup checks.

The authority model is also corrected: **the Thursday schedule buy/sell is the formal DO buy event when the DO explicitly approves the schedule.** The approved baseline is the exact presented version plus the DO directions recorded in that meeting. Schedulers then implement those directions and Gemini verifies implementation and second/third-order effects. There is no routine second DO buy. If implementation requires a materially different solution outside the recorded direction, that specific issue returns to the DO. Publication remains a separate human action, normally Friday.

The normal GenAI.mil scheduler workflow continues to use Gemini 3.7 Flash when available. The optional DO adversarial review remains a separate, read-only GPT-5.6 Terra or Grok Expert 4.5 conversation. Raw reviewer output has no authority; only DO-accepted human direction returns to the main scheduler workflow.

This release changes persistent Local Profile source material for both Pantons and first-time squadron setups. Existing installations must read **PERSISTENT MIGRATIONS.docx** and review the supplied reference-only profile copy. Merge only the approved workflow/authority language into the current human-maintained Local Profile. Do not overwrite Local Guidance automatically. Operational GenAI.mil behavior remains subject to the documented rehearsal/pilot validation process.
