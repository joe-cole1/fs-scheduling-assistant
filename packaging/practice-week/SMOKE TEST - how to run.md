# Smoke test: Tuesday prototype

This is a 20-minute check on a GenAI.mil computer. Everything here is fictional practice data.

## Before you start

- [ ] Copy the folder **Panton Scheduling Assistant (PROTOTYPE)** to your computer.
- [ ] Copy **PRACTICE WEEK (fictional)** to your computer.
- [ ] Open PRACTICE WEEK → **TESTER NOTES - do not upload.docx**. Keep it open beside the chat. Never drag it into the chat.

## Run it like a new scheduler would

- [ ] Open START HERE.docx and follow the 4 moves for Tuesday.
- [ ] Open a new GenAI.mil chat and turn on DoW Policies (GAMECHANGER).
- [ ] Drag in **TASK FILES → 1 TUESDAY - Plan next week.txt** and **Squadron Rules.docx**. Press Enter.
- [ ] When it asks for inputs, drag in every file in **PRACTICE WEEK → Inputs**.
- [ ] Do exactly what each YOUR NEXT STEP box says. Type HELP once to see what happens.
- [ ] Ask one planning question in step 5 (example: Which day should FALCON's checkride go on?).
- [ ] Save the WEEK FILE it gives you.

## Record what happened

- [ ] Mark each B and S line in TESTER NOTES as Seen, Not seen or Wrong.
- [ ] Note the model name shown and whether GAMECHANGER was on.
- [ ] Note how many files one message accepted.
- [ ] Copy the assistant's replies and the WEEK FILE into a document for review.

Send back the marked notes, the replies and the WEEK FILE. Remove anything that is not fictional before sharing. Those results decide what changes before the other task files are built.
