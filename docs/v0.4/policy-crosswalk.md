## Conflicts resolved explicitly

1. **Sell versus buy:** the latest DO decision puts formal buy after correction and assistant QC. Earlier planning shorthand and v0.3's lack of a sell state do not override it.
2. **Actual results:** v0.3 allowed actual-time duty reasoning but restricted target-week outcome inputs to retrospectives. v0.4 distinguishes live execution and cutoff-valid actuals from later hindsight.
3. **Quiet ingestion versus questions:** bulk uploads remain quiet, while an explicit planning question receives a bounded answer before a full review is requested.
4. **Missing evidence versus human confirmation:** preserve missing-check warnings, but close an identified concern when a human explicitly confirms it. Do not impose a new proof requirement or create an unspoken waiver.
5. **Recovery churn versus daily authority:** full-line recovery cascades remain analyzable. Daily approval boundaries determine the human action needed; the assistant does not silently narrow the preserved optimization policy.
