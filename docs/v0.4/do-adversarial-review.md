# Optional independent DO review

Use the one-page **07 Thursday - DO Adversarial Review.docx** checklist in System → Instructions and its complete prompt in System → Prompts. No particular model is required. This is a separate human-started, read-only review; **Do not delegate to subagents.**

Upload the startup instructions, current local guidance, exact candidate, actual sources and complete weekly QC record. The detailed review contract is in the primer’s guided-command section. The reviewer challenges hard constraints, sources, training flow, downstream effects, commander intent and minimum-change solutions. It reports NO MATERIAL OBJECTION, REVIEW ADVISED or MATERIAL CONCERN with evidence, consequence, confidence and recommended DO action.

An unsupported regulatory concern is REGULATORY QUESTION FOR MAIN GAMECHANGER VERIFICATION, never a confirmed violation. The DO decides which concerns merit action. Only the exact DO-accepted question or direction returns to the main chat. Record it with the complete human-decision prompt. Reviewer output creates no approval or waiver and never becomes an automatic second scheduler.
