# First-time squadron setup

Download the appropriate ZIP from [README](../../README.md) and open START HERE.docx. Operators use day/step numbered Word guides; GitHub is not required inside GenAI.mil.

Maintained guide sources begin with [first setup](../../packaging/guides/01-setup.md), then the chronological weekly flow: [Monday inputs](../../packaging/guides/02-monday-inputs.md), [Tuesday start](../../packaging/guides/03-tuesday-start.md), [Tuesday planning](../../packaging/guides/04-tuesday-plan.md), [Wednesday build](../../packaging/guides/05-wednesday-build.md), [Thursday QC](../../packaging/guides/06-thursday-qc.md), [optional DO review](../../packaging/guides/07-thursday-do-review.md), [Thursday buy/sell](../../packaging/guides/08-thursday-buy-sell.md), [buy/sell implementation](../../packaging/guides/09-apply-buy-sell-changes.md), [Friday publication](../../packaging/guides/10-friday-final-qc-publish.md), [execution reflows](../../packaging/guides/11-execution-reflows.md), [handoff](../../packaging/guides/12-handoff.md), [update](../../packaging/guides/13-update.md), and [check the setup](../../packaging/guides/14-check.md). The [blank local profile](../../templates/setup/local_profile_template.md) supplies no Pantons defaults.

The permanent extracted folder holds replaceable System instructions, persistent Local Guidance, a blank weekly folder to copy, and human-created Week of date folders. Existing approved local content stays authoritative. Setup is administrative Q&A, not a sixth operational phase.
